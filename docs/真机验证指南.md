# 真机验证指南

模拟器在这台机器上跑不起来（缺 AEHD 加速驱动，纯软件模拟会卡死），
所以功能验证要靠真机。这份文档写清楚怎么插手机、跑哪些测试、看什么。

## 一、手机准备（只需一次）

1. 设置 → 关于本机 → 连点「版本号」七次，开启开发者选项。
2. 设置 → 系统 → 开发者选项 → 打开「USB 调试」。
3. 用数据线插到电脑（有些手机要选「传输文件」模式，不能只充电）。
4. 手机上会弹「是否允许 USB 调试」，勾选「一律允许」并确定。

确认连接：
```
adb devices
```
应该看到一串字符加 `device`。如果显示 `unauthorized`，就是手机上没确认。

## 二、装 app

```
adb install -r C:\AndroidProjects\TripLog\app\build\outputs\apk\debug\app-debug.apk
```

`-r` 是覆盖安装，保留数据。装完在手机桌面找到「出行记」图标。

## 三、跑插桩测试（重点）

插桩测试会真的操作数据库、真的打 zip 包、真的渲染 Compose 界面，
比单元测试更接近实际使用。APK 已经编译好了：

```
adb install -r C:\AndroidProjects\TripLog\app\build\outputs\apk\androidTest\debug\app-debug-androidTest.apk
```

然后跑全部：
```
adb shell am instrument -w -r com.linqi.triplog.test/androidx.test.runner.AndroidJUnitRunner
```

或者用 Gradle（更省事，会自动装）：
```
gradle :app:connectedDebugAndroidTest
```

看结果：
```
adb logcat -d | findstr /C:"TestRunner"
```

### 测什么

备份往返测试（data/backup/BackupManagerInstrumentedTest.kt）：
- 导出再恢复，数据条数一致
- 恢复后字段完整保留（站点、时间、车次、座位、票价、乘车人、备注、类型）
- 恢复后 id 不冲突
- 恢复后「已提醒」标记重置
- 导出的 zip 里确实有 data.json
- 喂一个非备份文件，应该给出明确错误而不是崩溃
- 空库导出恢复不报错

Compose 界面测试（ui/ComposeComponentsTest.kt）：
- 空态文案能显示
- 起终点行渲染
- 表单输入能触发回调
- 时间标签格式化
- 深色模式能包裹内容
- 按钮点击能触发

这些测试的意义：它们验证的是「真机环境下代码跑不跑得起来」，
而不只是逻辑对不对。单元测试用 Robolectric 模拟 Android，
插桩测试用真的 Android。

## 四、手动功能核对清单

装上之后按这个顺序过一遍，每步都能立刻看出有没有问题：

添加流程
1. 点右下角「添加」。
2. 填出发地「上海虹桥」、目的地「北京南」，点出发时间选个未来日期和时间。
3. 保存。列表应该出现这条，在「即将出发」分区。

AI 识别流程
4. 底部「我的」→ AI 设置。
5. 填接口地址（如 https://api.deepseek.com/v1）、模型名、API Key。
6. 点「测试连接」，应返回「连接成功」。
7. 回到行程页，添加 → 顶部「选择截图识别」→ 选一张车票截图。
8. 等几秒，表单应该被自动填上，核对后保存。
9. 进详情页，应该能看到车票缩略图。

搜索和筛选
10. 列表顶部搜「上海」，应该只剩出发地或目的地含上海的。
11. 点「飞机」筛选 chip，应该只剩飞机。

删除
12. 在任意一条上左滑，出现红色删除背景，滑到底松手，该条消失。
13. 长按任意一条，顶栏变成「已选 N 条」，点「全选」再点「删除」，列表清空。

提醒
14. 添加一条 5 分钟后出发的行程，提醒选「1小时」。
15. 时间到应该收到通知，点通知跳到该行程详情。
16. 如果收不到，检查设置里 app 的通知权限有没有被关。

备份
17. 「我的」→ 导出与备份 → 导出备份，选个保存位置。
18. 删掉几条行程。
19. 回导出与备份 → 选择备份文件恢复 → 确认。
20. 删掉的行程应该回来了，车票图也在。

统计
21. 「我的」→ 打开统计。
22. 应该看到总览三格、交通工具占比条、常去城市、月度明细。

## 五、看日志排错

```
adb logcat | findstr triplog
```

崩溃信息会带包名。如果 app 白屏，先看这里有没有异常栈。

## 六、卸载清数据

```
adb shell pm clear com.linqi.triplog
```
清掉数据库、图片和设置（含 AI 配置），相当于恢复出厂。卸载：
```
adb uninstall com.linqi.triplog
```
